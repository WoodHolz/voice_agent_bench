# 标注规范（草案）

## 标注单位

每条样本表示一次控制决策：给定历史对话、最新用户话语和当前候选动作，选择唯一动作。

## 特殊标签

- `WAIT`：用户话语明显未完成，当前不应执行业务动作。
- `OTHER`：用户表达完整，但不匹配任何已有业务动作。

## 标注流程

1. 先判断话语是否完整；不完整时标注 `WAIT`。
2. 再判断是否存在匹配的业务动作。
3. 没有匹配动作时标注 `OTHER`。
4. 存在多个可能动作时，根据产品文档中的优先级规则处理；若规则未定义，将样本标记为 `needs_review`，不要自行猜测。
5. 只有控制流程需要的实体才写入 `gold_slots`。

## 复核要求

- 高风险动作必须由两人独立标注。
- 同一会话及其改写使用同一个 `group_id`。
- 有争议的样本先进入 `drafts`，裁决后才能进入固定数据划分。
