## 1. P0 — 填写口径（a5 / 7-54）

### 1.1 原定义

| 字段 | 原文档内容 |
| ---- | ---------- |
| **旁路** | **a5** 填写口径 |
| **触发信号** | 「怎么填 / 算不算一段」（意图 **7-54**） |
| **处置（冒烟期）** | 暂缓，统一「记录反馈 + 顾问回复」 |
| **子分支** | —（目标态建知识库） |
| **返回值** | 记录反馈 → **1-4-f** 跟进外呼 |
| **意图描述（7-54）** | 询问填写规则与判定标准；例：「工作经历怎么算一段？」 |
| **对应话术（表5）** | —（冒烟期记录反馈） |

### 1.2 RAG 建议

| 项 | 建议 |
| -- | ---- |
| 触发 | 意图引擎命中 **7-54**，或 **b14-2-b（7-43）** 后进入口径而非纯操作卡点 |
| 知识切片 | 工作经历分段、在职/离职证明人规则、授权字段释义、常见「算不算」FAQ |
| 未命中 | 回落 **a5** 冒烟策略 → 记录反馈 / 或 **a6-2** 口径超纲 |
| 红线 | 不编造客户定制规则；不确定 → 人工 |

## 3. P1 — 已提交能不能改（a4-3 / 7-52）

### 3.1 原定义（表2 · a4 / 表7 · 7-52）

| 原标号 | 内容 |
| ------ | ---- |
| **7-52** | 要求修改已提交；例：「我名字填错了，能改吗？」→ **a4-3**、**5-1-b-2-c**、超纲 **a6-2** |
| **a4-3-a** | 未提交 / 可接受：「先正常提交…审核时再联系」→ 顾虑解除 → 回主线断点 |
| **a4-3-b** | 已提交且坚持要改 |
| **a4-3-b-1** | 授权书签完不可回退 → 「改不了＋备注补救」 |
| **a4-3-b-2** | 表单字段 → 系统退回重填（第一版备注） |
| **a4-3-b-3** | 证明人 → 可补/可删/顾问代填（第一版备注） |
| **a4-3-b-4** | 超出以上（变更授权主体等）→ 第一版备注 / 转人工 |

主线挂载：**5-1-b-2-c**（意图 **7-52**）→ 可接受则进入 **6**；否则按 **a4-3** / **a6**。

### 3.2 RAG 建议

| 项 | 建议 |
| -- | ---- |
| 触发 | **7-52**；若候选人描述落入 **a4-3-b-1~4** 以外 → **a6-2** |

## 4. P2 — 自主寻访（a3-6 / 7-57~7-59）

### 4.1 原定义

| 原标号 | 内容 |
| ------ | ---- |
| **a3-6-a** | `informed`：意愿确认环节主动告知 + 征求同意 → 话术 **5-38** |
| **a3-6-a-1 / 7-57** | 同意 → 记录 consent → 回主线 |
| **a3-6-a-2 / 7-58** | 顾虑=怕在职暴露 → 同 **a3-1 / 7-29** |
| **a3-6-a-3 / 7-59** | 拒绝 → 记录「仅用已提供证明人」→ `provided_only` → 回主线；话术 **5-40** |
| **a3-6-b** | 默认 `provided_only`；证明人失联 → **5-39** |

表5：

| 原标号 | 场景 | 模板要点 |
| ------ | ---- | -------- |
| **5-38** | 自主寻访-征求同意（冒烟期暂缓） | 可能通过公司官方渠道联系其他在职同事…可以吗？ |

| **5-40** | （意图表指向）拒绝自主寻访 | 见意图 **7-59** 对应列 |

### 4.2 RAG 建议

优先用**任务卡配置**（informed vs provided_only）；仅当候选人追问「法律上能不能 / 会联系谁」时 RAG 政策条文。

## 7. 运行时挂钩（与 FSM 交界）

```
每轮候选人发言
  → 表7 意图识别
  → 若 intent ∈ {7-54, 7-31, 7-52, 7-57..59?, 7-13深化?, 超纲7-51/53?}
       → RAG 检索（带 identity_mode / 订单配置过滤）
       → 生成应答 → 再走原旁路返回值（回断点 / 1-4-f / a6）
  → 否则
       → 文件03 封闭状态机
```

挂载点（原主线）：

| 进入路径 | 原标号 |
| -------- | ------ |
| 归因后「有问题」 | **5-1-b-2** → **a4** 或 **a5**（**7-43**） |
| 意愿阻力 | **5-1-b-3** → **a3**（**7-44**） |
| 开场/中途信任 | **a1**（仅 **7-13** 可选 RAG） |
| 意愿确认环节 | **a3-6**（若启用 informed） |
